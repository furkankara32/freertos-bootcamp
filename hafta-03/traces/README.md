# Özgün trace dosyaları

Kayıt aracı özgün `.SVDat` dosyalarını ham seri/CSV/metadata ile aynı `measurements/hardware/session-...` klasöründe saklar. Oturumun `session.json` dosyası altı trace açık koşuya indeks verir. Aynı dosyayı iki yerde değiştirerek kanıtı ayırmamak için burada kopya üretilmez.

Henüz F407 kaydı yoktur. Kart testi sonunda SystemView'de açılan özgün oturum yolunu bu dosyaya ekle. Trace OFF koşusunda SVDat bulunmaması beklenir.
